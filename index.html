    Settings

    Team access, imports and backups.

    Team

    Import from Excel

    Worksheets named AI, Data or DevOps, or one sheet with a Course column. Matching student, course and batch rows are updated; new rows are added.

    Backup

    One file with every record and resume. Restoring replaces the current data for everyone.

    Duplicates

    Students are matched by name, course and batch. Batch spellings such as "Batch 2", "batch-02" and "Batch 02" are treated as one batch and saved as "Batch 02". Duplicates are merged automatically when you upload Excel, and you can run the check yourself here.

    Clear data

    Admins only. Removes every student record, rating, exam score and comment for the whole team. The activity log is kept. Download a backup first if you may need the data again.

    Storage

    Clear all data?

    This removes for everyone on the team. It cannot be undone.
